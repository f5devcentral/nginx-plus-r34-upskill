## Introduction

This section will go through steps for how to setup forward proxy support for E&V.

## Configure E&V to use a forward proxy

Assuming that a forward proxy configured at nginx-forward-proxy.lab.f5npi,
listening on port 8888, add the following line to the mgmt{} section of
/etc/nginx.conf:

```shell
   proxy nginx-forward-proxy.lab.f5npi.net:8888;
```
Restart NGINX Plus R34:

```shell
systemctl restart nginx
```

Confirm success in the nginx-plus error log:

```shell
tail /var/log/nginx/error.log
```

Example output:

```shell
2025/03/24 14:07:06 [error] 1063#1063: proxy returned 400 during usage report to product.connect.nginx.com (via 10.1.1.9:8888)
```
