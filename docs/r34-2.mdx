## Configuration

In this demo, a forward proxy is configured at nginx-forward-proxy.local,
listening on port 8888.

Add the following line to the mgmt{} section of
/etc/nginx.conf:

```shell
   proxy nginx-forward-proxy.local:8888;
```
Restart NGINX Plus R34:

```shell
systemctl restart nginx
```

Confirm success in the nginx-plus error log:

```shell
tail /var/log/nginx/error.log
```
